# Atmos — Modern React Weather App

A modern weather app built with React, JavaScript, Tailwind CSS and Open-Meteo.

## Features

- City search using Open-Meteo Geocoding API
- Current weather conditions
- 7-day forecast
- Humidity, wind, feels-like temperature and rain probability
- Modern two-tone gradient UI
- Responsive design
- Weather displayed in a modal
- City review/rating section
- Reviews persisted with localStorage
- Popular city quick-access cards
- No API key required

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in your terminal.

## APIs

City search:
https://geocoding-api.open-meteo.com/

Weather:
